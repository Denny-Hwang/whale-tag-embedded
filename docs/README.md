# Whale Tag Embedded — Reverse-Engineering Documentation

Reverse-engineering documentation for this repository, available in two languages:

- 🇰🇷 **한국어**: [`docs/kr/`](kr/README.md)
- 🇬🇧 **English**: [`docs/en/`](en/README.md)

Both editions cover the same content: project overview, the Docker/QEMU image build
pipeline, the `cetiTagApp` architecture, the mission state machine and burnwire logic,
sensors and the FPGA audio pipeline, the recovery board, and the test infrastructure with
a verified list of issues found during analysis.
